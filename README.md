# سنتر ايكون التعليمي (Icon Center)

نظام متكامل وموقع إلكتروني خاص بـ **سنتر ايكون التعليمي**، يجمع بين واجهة عامة للطلاب للتعرف على مواعيد الحصص وأسعارها والمدرسين، ولوحة تحكم داخلية لإدارة الحضور الذكي بالـ QR Code وحسابات المدرسين والمصروفات.

---

## 📚 وثائق المشروع (Documentation)

- 📄 [وثيقة متطلبات المنتج (PRD)](docs/PRD.md): تشمل كافة أهداف المشروع، صفحات الموقع، الصلاحيات، وآلية رصد الحضور والتسويات المالية.
- ⚙️ [وثيقة البنية التقنية (Tech Stack)](docs/STACK.md): توضح معمارية العمل على بيئة مجانية 100% بالاعتماد على (Next.js + Supabase + Vercel + GitHub).

---

## 🎯 الميزات الرئيسية للنظام

1. **الواجهة العامة للجمهور (SEO Optimized):**
   - استعراض جدول الحصص اليومي والأسبوعي المحدث.
   - قائمة بأسماء المدرسين وصورهم والمواد الدراسية.
   - تفاصيل الاتصال السريع وموقع السنتر على خرائط جوجل.

2. **نظام الحضور الذكي بالاستقبال:**
   - قراءة كارت الطالب والـ QR Code بكاميرا الموبايل لتأكيد الحضور بضغطة زر.
   - تنبيهات فورية لموظف الاستقبال بالمتأخرات المالية للطلاب.
   - إمكانية البحث اليدوي بالاسم عند نسيان الطالب لكارته.

3. **استوديو كروت الطلاب:**
   - توليد وتصدير كروت هوية شخصية أنيقة بشعار السنتر قابلة للطباعة بصيغة PDF.

4. **الإدارة المالية وتسويات المدرسين:**
   - حساب تلقائي لنسبة السنتر من كل حصة وتسوية مستحقات المدرسين.
   - إدارة وتسجيل المصروفات العامة لمعرفة صافي أرباح السنتر الحقيقية.
